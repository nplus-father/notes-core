# 人文／人生筆記星系 → note 領域規劃盤點

以 `books-management/books-done/` 藏書為源，規劃「人文／人生筆記星系」（與技術星系並列，皆部署於 `nplus.wiki/<note-name>/`）。
延續技術站慣例：一站一 Astro（`note-template`），concept 逐則整合多書，跨站以 `seeAlso` 互連，各頁 `furtherReading` 連到線上書 `https://nplus.wiki/<slug>/`。

> 產出：2026-07-02 全庫掃描。書名為 books-done 資料夾 slug；↗ 表跨站共用（多站引用同一本）。
> 顆粒度：以下 14 站為建議值。可併（創業＋商業策略、思考＋成長）縮到 ~11 站，或再拆（行銷、關係）到 ~16 站。
